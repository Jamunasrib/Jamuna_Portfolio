JAMUNA SRI B — PORTFOLIO STARTER

1) Install Node.js LTS from https://nodejs.org/
2) Extract this ZIP into a folder.
3) Open the folder in VS Code.
4) Open Terminal > New Terminal.
5) Run:
   npm install
   npm run dev
6) Open http://localhost:3000 in your browser.

BEFORE DEPLOYING:
- Replace https://github.com/ with your real GitHub profile URL in app/page.tsx.
- Replace https://www.linkedin.com/ with your real LinkedIn profile URL.
- Replace YOUR_EMAIL@example.com with the email address you want recruiters to use.
- Add your actual resume PDF at public/resume.pdf. The resume button will download it.
- Review all project descriptions and technologies to ensure they match what you personally built.
- Add real GitHub repository/demo links when available. Current project links intentionally point to the Contact section.

DEPLOY:
1) Push the project to a GitHub repository.
2) Sign in to https://vercel.com/ using GitHub.
3) Select Add New > Project and import the repository.
4) Keep the default Next.js build settings and click Deploy.
5) Test the live site and all links on desktop and mobile.

This is a starter portfolio; verify content and links before sharing it with recruiters.
